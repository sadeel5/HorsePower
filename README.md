# 🚗 Horse Power Tuning Cars

A modern and responsive website for **Horse Power Tuning Cars**, a performance tuning and ECU programming workshop based in Amman, Jordan.

## 🌟 Features

- 🎥 Full-screen hero video
- 🚘 Performance services section
- 📹 Video gallery (Our Work)
- 📱 Fully responsive design
- 💬 WhatsApp booking form
- 📍 Contact information
- 🔝 Back-to-top button
- ✨ Scroll animations

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts
